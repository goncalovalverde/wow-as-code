## Checklist

### Week 1 — Environment & Context

- [ ] Development environment set up and building locally
- [ ] Access to all required systems (GitHub, Jira, Slack, CI/CD)
- [ ] Read team ways of working (`wow/` directory)
- [ ] Understand the inheritance model (company → unit → team)
- [ ] Pair with a team member on a small PR

### Week 2 — First Contribution

- [ ] Complete first PR following code review norms
- [ ] Understand the Definition of Done checklist
- [ ] Review architecture principles and data access patterns
- [ ] Attend sprint planning and retro

### Week 3 — Independence

- [ ] Take ownership of a story end-to-end
- [ ] Give your first code review using team norms
- [ ] Identify one process improvement suggestion

## Rationale

Structured onboarding reduces time-to-productivity from months to weeks. This checklist surfaces automatically when a new member joins the team.
